# Deci

**Simple jvm version**

While [deci-multi](../deci) supports JVM, JS, and iOS, and is highly optimized, 
these features also make it considerably more complex.

Here is a simple JVM-only implementation without additional optimizations. 
It is built with Maven and is intended for projects that do not require multiplatform support.

This version still used in production.

**Usage**
Use maven dependency:

```xml
<dependency>
    <groupId>com.github.labai</groupId>
    <artifactId>deci</artifactId>
    <version>0.2.0</version>
</dependency>
```
